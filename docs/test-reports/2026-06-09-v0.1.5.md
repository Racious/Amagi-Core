## 實測 A — 差異匯出目錄修復

### ⚠️ 波折①：找不到 `ddos-backend` 路徑
- **現象**：`projects.json`（專案設定）遍尋 `%APPDATA%`／`%LOCALAPPDATA%` 皆無，無法取得 ddos-backend 路徑。
- **解法**：改用 **Amagi-Core 自身的未追蹤目錄 `docs/ui-layout-concepts/`**（6 個文字檔）——與 `uploads/` 同為「未追蹤目錄折疊」場景，且為文字檔，能額外驗證「展開後可正常產 diff」。`-uall` 為 git 通用行為，結論適用於 ddos-backend。

### A-1／A-2：git 折疊行為對比
| | 指令 | 輸出 |
|--|------|------|
| 舊（bug） | `git status --porcelain` | `?? docs/ui-layout-concepts/`（折疊成單一目錄項） |
| 新（修復） | `git status --porcelain -uall` | 展開成 6 個實際檔案（README.md / app.css / app.html / app.js / index.html / styles.css） |

✅ 證實 `-uall` 根治折疊。

### 🐞 問題③：長主題名截斷（發現並修復）
- **現象**：「Catppuccin Latte／Mocha」「Everforest」在窄卡片中被裁切丟字。
- **根因**：主題卡 label 在 flex 容器缺 `min-w-0`（flex 子項預設 `min-width:auto`，不准縮至內容寬度以下 → 長文字溢出被裁）。
- **解法**：label 加 `min-w-0 break-words`（兩處）。
- **驗證**：HMR 套用後截圖確認文字完整換行；`npm run build` 編譯通過。
