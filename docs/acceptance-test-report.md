## 5. 測試中遇到的問題與解法

1. **打包「存取被拒」(os error 5)**
   - 因：build 要覆寫正在執行的 `amagi-core.exe`。
   - 解：打包前先關閉執行中的實例（已納入流程）。
2. **本機簽章打包報「找不到私鑰」**
   - 因：開啟 `createUpdaterArtifacts` 後，連本機 build 也需簽章金鑰；首次未帶金鑰。
   - 解：本機以 `TAURI_SIGNING_PRIVATE_KEY` 指向本機金鑰檔重跑 → 產出 `.sig`、金鑰驗證通過。安裝檔本身在未簽章時仍會產生，不影響本機安裝測試。
3. **雙托盤根因釐清**
   - 因：`tauri.conf.json` 的 `trayIcon` 與 `tray.rs` 的 `TrayIconBuilder` 各建一個。
   - 解：移除設定檔的 `trayIcon`，保留功能完整的程式化托盤。
